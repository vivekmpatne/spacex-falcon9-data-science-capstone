# Datasets

This folder contains the datasets used in the SpaceX Falcon 9 Data Science Capstone Project.

The datasets are collected and prepared during the data collection and data wrangling stages of the project.

## Data Sources

- SpaceX API
- Web scraping

## Purpose

The datasets are used for:

- Data wrangling
- Exploratory Data Analysis
- SQL analysis
- Data visualization
- Interactive visual analytics
- Machine learning prediction

Additional dataset files will be added to this folder as part of the completed project workflow.
