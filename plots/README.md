# Plots and Visualizations

This folder contains the plots and visual outputs generated during the SpaceX Falcon 9 Data Science Capstone Project.

The visualizations support the exploratory data analysis, interactive visual analytics, and predictive analysis stages of the project.

## Visualization Categories

- Exploratory Data Analysis plots
- Launch site analysis
- Payload analysis
- Launch outcome analysis
- Yearly launch trends
- Folium map visualization
- Plotly Dash visualizations
- Machine learning evaluation plots
- Confusion matrix and model evaluation results

The relevant visualization files will be added to this folder as the project artifacts are organized.
